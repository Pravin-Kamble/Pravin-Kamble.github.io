## 🌐 How to Host on GitHub Pages (Step-by-Step)

### Option 1: Your Main Portfolio Domain (`https://pravin-kamble.github.io`) — *Recommended*

1. Log into your GitHub account: **[github.com/Pravin-Kamble](https://github.com/Pravin-Kamble)**.
2. Click **New Repository**.
3. Name the repository exactly:
   ```text
   Pravin-Kamble.github.io
   ```
4. Set the repository visibility to **Public** and do NOT initialize with a README (keep it empty).
5. Open your terminal in this `portfolio` folder:
   ```bash
   cd C:\Users\lenovo\.gemini\antigravity\scratch\portfolio
   git init
   git add .
   git commit -m "Launch Pravin Kamble developer portfolio"
   git branch -M main
   git remote add origin https://github.com/Pravin-Kamble/Pravin-Kamble.github.io.git
   git push -u origin main
   ```
6. That's it! GitHub Pages deploys automatically. In about 60 seconds, your portfolio will be live at:
   👉 **`https://pravin-kamble.github.io`**

### Option 2: Under a Project Repository (`https://pravin-kamble.github.io/portfolio/`)

If you prefer keeping your main domain for something else:
1. Create a public repository named `portfolio` on GitHub.
2. Push your files:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Pravin-Kamble/portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** → **Pages** → under **Build and deployment** select **Deploy from a branch** (`main` / `root`) and click **Save**.
